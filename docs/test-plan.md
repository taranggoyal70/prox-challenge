# ArcLens test plan

Generated by `/autoplan` engineering review on 2026-10-26.

> **Coverage plan:** this file records the complete intended release matrix, including future browser, image, persistence, hosted-auth, chaos, and live-provider suites. It is not a claim that every listed suite ships in this assessment. Run `npm run test`, `npm run eval:offline`, and `npm run verify` for the implemented gates; see [Commands](commands.md) and the current test tree for executable coverage.

## Framework

- Vitest for unit, property, contract, and integration tests.
- Playwright plus axe-core for browser, accessibility, responsive, and user flows.
- Deterministic provider, clock, budget, image, filesystem, and SDK-process fakes.
- Live eval runner only for explicitly authorized cost-bearing suites.

## Coverage map

```text
KNOWLEDGE
 PDF input
  ├─ valid pinned toolchain -> manifest/facts/images [UNIT+INTEGRATION]
  ├─ missing/wrong checksum -> actionable integrity error [UNIT]
  ├─ rotated/vector/image-only page -> stable region [GOLDEN]
  └─ cross-platform regenerate -> byte compare [CI]

QUESTION
 HTTP input
  ├─ invalid/oversized -> ArcLensError [CONTRACT]
  ├─ admission/quota fail -> typed retry/budget error [INTEGRATION]
  └─ admitted -> request transaction
       ├─ retrieval empty -> clarification/abstention [UNIT+EVAL]
       ├─ tool retry -> semantic dedupe [UNIT]
       ├─ model free text only -> one repair -> error [FAKE SDK]
       ├─ invalid claim/fact/artifact -> reject [PROPERTY+MUTATION]
       ├─ valid envelope -> atomic bundle + done [INTEGRATION]
       └─ cancel/timeout/disconnect/crash -> cleanup + one terminal [RACE+CHAOS]

OWNER FLOW [E2E]
 first screen -> context -> hard prompt -> status -> answer -> artifact -> Proof
  ├─ clarification + Not sure + edit context
  ├─ hazard stop precedes all content
  ├─ partial artifact/source failure preserves answer
  ├─ no-key recorded proof never looks live
  └─ export case includes/excludes exact fields

PHOTO
 bytes -> header -> decode -> sanitize -> observation -> compare
  ├─ animation/pixel bomb/metadata/parser timeout -> reject + cleanup
  ├─ wrong/low-light/hostile/multiple machine -> inconclusive + recovery
  ├─ visible match/discrepancy/not observable -> bounded result
  └─ cancel/process kill -> bytes deleted, lease/budget released

KNOWLEDGE OPS
 draft -> evidence -> verify -> publish transaction -> outbox -> impacted eval
  ├─ conflict/expiry/supersede/rollback
  ├─ unauthorized/CSRF/origin fail
  └─ disk-full/crash/concurrent publish/corruption -> safe degraded state
```

## Unit and property suites

- SourceRef page/region bounds, coordinate normalization, rotation, checksum, anchors.
- Ranker tokenization, aliases, phrase/tag boosts, empty/Unicode/huge query.
- Deterministic facts and computation receipts; all known duty/polarity/troubleshooting variants.
- Claim grammar, server-derived safety classes, prose evidence spans, qualification context.
- Artifact schemas, semantic IDs, canonical hashes, receipt references.
- Event parser property/fuzz tests: UTF-8, newline splitting, max line, sequences, unknown versions/types.
- Config modes, precedence, ranges, invariant weakening, old env-name rejection, direct `process.env` ban outside config.
- ArcLensError completeness and secret/path/image redaction.
- Session LRU/leases/TTL/capacity with fake clock.
- Budget reservations/reconciliation under concurrency.
- Image headers, frames, dimensions, metadata, decoder limits, cleanup.
- SQLite migrations, transactions, outbox, rollback, crash points, disk-full/read-only/corruption.

## Integration suites

- Agent SDK adapter with fake in-process MCP calls and actual installed SDK type/API contract.
- Request transaction commit/discard/idempotency and repair turn.
- NDJSON route with backpressure, proxy-buffer simulation, disconnect, timeout, cancellation.
- Two simultaneous sends, cancel/done, reset/active, retry IDs, session restart/recovery.
- Signed cookie/cross-conversation access, Origin/CSRF/admin exchange.
- Knowledge generator temporary regeneration and byte compare.
- Health/readiness capability matrix by mode.
- Documentation snippets, examples, commands, schemas, env names, links.

## Browser/E2E suites

- Three challenge prompts and exact artifact oracles.
- First run in no-key and live-local modes.
- Desktop/tablet/320px/landscape; keyboard; high zoom; forced colors; reduced motion.
- Focus trap/restore, live-region cadence, diagrams' table equivalents, 44px targets.
- Key/model/provider/timeout/budget/integrity/error recovery.
- Session busy/capacity/recovery/cancel terminal copy.
- Recorded proof banner, no live input, fixture metadata.
- Photo slot lifecycle, privacy consent, recapture, deterministic fallback.
- Support-case timeline, review-before-export, printable brief.
- Hostile Markdown, links, Unicode bidi, path traversal, source IDs, CSP.

## Live eval suites

- PR smoke: 8 cases, ≤$2, ≤8 min.
- Core: 40 independently labelled cases, ≤$12, ≤30 min, sealed scoring implementation outside tuning path.
- Extended: up to 40 cases, ≤$12, only for shipped optional features.
- Safety and deterministic categories require 100%; repeat stochastic safety cases enough to detect variance.
- Store request/model/prompt/corpus/schema versions, tools, receipts, envelope, artifacts, latency, cost, and case-level failure.
- Atomic suite budget and incomplete-run failure semantics.

## Mutation suite

The gate must fail when a mutation:

- flips polarity or duty-cycle fact;
- changes PDF page/region mapping;
- removes a citation/qualification/full-page context;
- enables a built-in Agent SDK tool;
- bypasses `submit_answer`;
- trusts a model-derived artifact value;
- disables image sanitation or hosted auth;
- commits artifacts before answer validation;
- emits two terminal events;
- leaks a secret, path, or image byte;
- weakens a safety category threshold;
- allows unsigned/forged recovered assistant history.

## Release-blocking failures

- Any deterministic/safety case failure.
- Any critical path without specific error handling and a failure test.
- Any unauthorized tool, mutation route, source path, or model URL.
- Any stale/corrupt knowledge or replay fixture.
- Citation precision/recall below 95%, clarification below 90%, valid artifacts below 95%, or holdout aggregate below 90%.
- Clean-clone or first-result DX gate failure.
