## Vision

### 10x Check

The 10x outcome is not more chat features. It is a support agent whose physical observations, technical claims, and generated interfaces are inspectable and falsifiable. The flagship proof is a setup photograph that the system compares against exact source-backed expectations before it lets the user proceed.
